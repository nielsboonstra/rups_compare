# rups_compare
Vergelijk eenvoudig twee jaargangen van de RUPS-planning voor jouw project met deze tool. Je hoeft enkel twee RUPS-planningen te uploaden in de webapp, en het achterliggende script doet de rest. Als output krijg je een Excel-export van gewijzigde, verwijderde en toegevoegde RUPS-maatregelen te zien tussen de twee jaren.
